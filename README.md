# Sales Dashboard — Excel 2025

An interactive Excel sales dashboard built to analyze and visualize sales performance data across multiple dimensions.

## Overview

This project demonstrates data analysis and visualization skills using Microsoft Excel, including PivotTables, dynamic charts, and an interactive dashboard layout.

## Features

- Interactive sales dashboard with slicers
- Revenue and quantity trend analysis
- Product and category performance breakdowns
- Dynamic filtering by time period or segment
